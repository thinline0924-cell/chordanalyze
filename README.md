# CHORD NOTE

作曲のときに横に開いておく早見帳です。ブラウザで開く1ページのサイトです。

- **進行**:J-POP・Jazz・終止・転調の 91 件。タブの中を「Ⅳ から始まる」「ターンアラウンド」などの小分類で区切っています。度数と実際のコード名を、リードシート(小節線つきの譜面)の形で並べ、詳細には YouTube・Spotify で使われている曲を探すリンクがあります
- **ダイアトニック**:メジャーと3種類のマイナー。3和音/4和音、機能(T・SD・D)つき
- **コードの使い所**:セカンダリードミナント、裏コード、サブドミナントマイナーなど 12 項目
- **テンション**:コードの種類ごとの使えるテンションと、ドミナントのテンションの選び方
- **スケール**:18 種類と、コードとスケールの対応表
- **分析**:U-FRET の曲のページの URL を貼るか、U-FRET・ChordWiki の曲のページでブックマークレットを押すと、そのコード譜を、このサイトの理論で分析します
  - キー(と転調)を判定し、全部のコードを度数にする
  - 67 件の進行と照らし合わせる(「サビは王道進行」など)
  - セカンダリードミナント・裏コード・借用和音・クリシェ・ベースラインなどの技法を見つける
  - 「流れ」(ブロックごとの説明)と「聴きどころ」を文章にする
  - 判定はすべて決まったルールで行います(AI は使いません)。歌詞は読み込まず、コードだけを使います

ほかに、次のことができます。

- 画面上部で**キー**を選ぶと、サイト全体が移調します
- **コード名を押す**と、オルガン風の音が鳴り、右(スマホでは下)に詳細が出ます。詳細の中身は、構成音、五線譜、押さえ方(6弦ルート・5弦ルート)、指板(0〜15フレット)、テンションです
- 進行と分析した曲は「保存」でホームに並びます。保存とキーは、そのブラウザの中に残ります
- 全部の項目の一覧(索引)は、上部の「索引」ボタン(スマホは「メニュー」)から開きます

APIキーやパスワードはいりません。
URL の読み込みのために、小さなサーバー(`server.js`)が動きます。U-FRET のページは、ほかのサイトの画面から直接は読めない決まり(CORS)になっているためです。追加のパッケージは使っていません。
ChordWiki は、プログラムからの読み込みを Cloudflare(人間かどうかを確かめる関所)で止めているので、サーバーからは読みません。ブックマークレットで、あなたが開いているページから読みます。

## 公開のしかた(GitHub → Render)

### 1. GitHub に新しいリポジトリを作ってファイルを上げる

1. <https://github.com/new> で新しいリポジトリを作ります(名前の例:`chordanalyze`)
2. 「uploading an existing file」を押し、このフォルダの中身を**フォルダごと**ドラッグします
   - `index.html` `style.css` `server.js` `package.json` `render.yaml` `README.md` `CLAUDE.md`
   - `js/` フォルダ、`lib/` フォルダ、`tests/` フォルダ、`.github/` フォルダ
   - `.github` は名前が「.」で始まるため、パソコンによっては見えません。見えなくても、サイトの表示には影響しません(自動点検が動かないだけです)
3. 「Commit changes」を押します

### 2. Render で公開する

1. <https://render.com> に GitHub アカウントでログインします
2. 右上の「New +」→「**Blueprint**」を選びます
3. 1 で作ったリポジトリを選びます
4. 「Apply」(または「Deploy」)を押します。入力する設定はありません
5. 数分待つと `https://chordanalyze.onrender.com`(この名前がほかの人に使われているときは、後ろに文字が付きます) のアドレスで開けます

Web サービス(無料プラン)は、15分ほど使わないと眠ります。眠っているときに開くと、最初の表示まで1分ほどかかります。

> 以前に「静的サイト」として公開していた場合は、Render の画面でその古いサービスを消してから、上の手順で作り直してください(2つあると、古いほうを開いて「分析」が動かないことがあります)。

### 自分のパソコンだけで見る

`index.html` をブラウザで開くだけでも、早見帳の部分は動きます。ただし「分析」の URL の読み込みはサーバーが必要なので使えません(「コードを貼り付けて分析する」は使えます)。

## 進行を足すとき

`js/data.js` の `PROGS` に1行足します。コードは**度数**で書きます(キーを変えると自動で移調されます)。

```js
{ id: 'my1', cat: 'pop', sub: 'basic', mode: 'major', name: '名前', alias: ['検索用の別名'],
  bars: 'IVM7 | V7 | IIIm7 | VIm',          // | は小節の区切り。1小節に2つなら 'Vm7 I7'
  mood: '雰囲気', use: '使い所', note: '解説', vars: [] },
```

- 書き方の例:`IVM7` `bVII7`(♭Ⅶ7)`#IVdim7`(♯Ⅳdim7)`IIm7(b5)` `V/VII`(分数コード)
- `sub` は小分類です。使える名前は `js/data.js` の `SUBS` にあります
- 使えるコードの種類は `js/theory.js` の `Q` にあります

## 分析の使い方

### U-FRET:URL を貼る

1. 上のメニューの「Analyze」を開きます
2. U-FRET の曲のページの URL(`https://www.ufret.jp/song.php?data=…`)を貼り、「分析する」を押します。共有でコピーした「曲名 … https://…」のままでも読めます
3. 「流れ」「聴きどころ」「譜面」「使われている技法」が出ます。譜面のコード名を押すと、音と詳細が出ます
4. 「選んだキー」を押すと、上で選んでいるキーに移調して表示します
5. 「保存」で、このブラウザの中に残せます(コードだけ)

### ChordWiki(と U-FRET):ブックマークレット

最初に1回だけ登録します。

- **PC**:「Analyze」ページの「CHORD NOTE で分析」の枠を、ブラウザのブックマークバーへドラッグします
- **スマホ**:「スマホで登録する(コードをコピー)」を押し、何かのページをブックマークに追加してから、その URL の欄をコピーした文字に置き換えて保存します

使うとき:ChordWiki か U-FRET の曲のページを開き、登録したブックマークを押します。新しいタブで分析ページが開きます。
コードだけを取り出して渡します(歌詞は渡しません)。データはサーバーに送りません。

### うまく読めないとき

「コードを貼り付けて分析する」に、`C G Am F` や `[C]歌詞[G]歌詞` の形で貼り付けても分析できます。
